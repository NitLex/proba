# Плати по миру — баннеры для РСЯ / медийки

Cyberpunk + premium fintech. Промокод **LG2026**, бонус **500 ₽**.

## Быстрый просмотр

Откройте в браузере:

```
banners/platipomiru/index.html
```

Все 19 размеров в одной странице.

## Экспорт PNG

```bash
cd banners/platipomiru
npm init -y
npm install puppeteer
node export.mjs
```

Файлы появятся в `export/`:

| Размер | Файл |
|--------|------|
| 1000×120 | platipomiru_1000x120.png |
| 1080×450 | platipomiru_1080x450.png |
| … | … |

## Размеры

1000×120, 1080×450, 1280×256, 160×600, 1706×184, 240×400, 240×600, 300×250, 300×300, 300×500, 300×600, 320×100, 320×480, 320×50, 336×280, 480×320, 728×90, 940×1524, 970×250

## Тексты на баннере

- **Заголовок:** Оплачивайте любимые игры
- **Подзаголовок:** Виртуальная карта для зарубежных игровых сервисов
- **Промо:** LG2026 → 500 ₽ на открытие карты
- **CTA:** Получить карту → platipomiru.com
- **Дисклеймер:** Подробные условия — на сайте platipomiru.com

## Для РСЯ

В объявлении укажите ссылку на лендинг `https://platipomiru.com` (с UTM при необходимости).  
Загрузите PNG нужного размера в креативы Директа.

## Файлы

- `assets/bg-hero.png` — AI-фон (геймер, RGB, неон)
- `styles.css` — стили всех макетов
- `index.html` — превью
- `export.mjs` — автоматический экспорт PNG
