# Куда вставить токен LeadGid

1. В списке файлов слева открой файл **`SECRETS.env`**
   (если не видишь — нажми на дерево файлов / File explorer агента).
2. Найди строку:
   ```
   LEADGID_TOKEN=
   ```
3. После `=` вставь свой длинный токен (начинается с `eyJ`).
4. Сохрани файл.
5. Напиши в чат: **токен вставил**

Не копируй токен в чат.
