## Что вычищено

Сид `карта онлайн` почти целиком увёл сбор в **гео/погодные карты**, не в платёжные:

1. **Осадки / погода / «в реальном времени»** — карта осадков, погоды, «на сегодня».
2. **СВО / Украина** — новостные карты боевых действий.
3. **Натальная / матрица** — астрология.
4. **Навигатор / маршрут / Яндекс.Карты / бензин** — GIS.
5. **Платные дороги / Госуслуги** — ассоциации к «оплата за границей».
6. **Синяя карта / SIM** — страховка в РБ и симки, не виртуальная Mastercard.
7. **ТВ / песни / поделки** — ассоциации к сиду «оформление за минуты».
8. **Займы / медкарта / межевание / скачать**.

Ошибка live: seed `Плати по миру - Выпуск карты` → `Invalid query` (тире/бренд). В следующие прогоны — короткие карточные сиды без названия оффера.

## Рекомендации для Директ-агента

1. Основные группы на тест: **Travel** и **Services**; **SBP** — третья (офферный крючок: скорость + промокод).
2. Ключи — из `keywords-*.txt` / JSON `groups.*.keywords[].phrase`.
3. Не возвращать широкие `карта онлайн` / `карты онлайн` без уточнения «виртуальная / для оплаты / подписок».
4. Автотаргетинг выкл.; после 2–3 дней — минус-площадки РСЯ по отчёту.
