## Что вычищено

Сид `карта онлайн` почти целиком увёл сбор в **гео/погодные карты**, не в платёжные:

1. **Осадки / погода / «в реальном времени»** — карта осадков, погоды, «на сегодня».
2. **СВО / Украина** — новостные карты боевых действий.
3. **Натальная / матрица** — астрология.
4. **Навигатор / маршрут / Яндекс.Карты / Google Maps / бензин / спутник** — GIS.
5. **SIM / ПВЗ / учётные и инвентарные карточки** — не платёжные карты.
6. **ТВ / песни / поделки** — ассоциации к сиду «оформление за минуты».
7. **Займы / медкарта / «бесплатно» / сервисный портал**.

Пайплайн: хук `карта онлайн` убран из playbook travel; агент `wordstat` фильтрует GIS-мусор и не шлёт плохие сиды в live API.
