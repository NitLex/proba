## Что вычищено

Сырой сбор сильно зашумел:

1. **МФО «Кредит 365»** — кабинет / вход / займ (чужой бренд, пересекается с минусом `займ`).

4. **Ассоциации к «премиальная / карта»** — войска, бункер, навигатор, маршруты.
5. **Контент travel** — блог, «смотреть онлайн».
