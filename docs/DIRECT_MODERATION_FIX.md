# Работа над ошибками: модерация РСЯ PPM

## Главная причина
Клик-ссылка `https://trekerarbitrag.ru/click/0BL6esOO` отдавала **403** для `YandexBot`,
потому что в кампании включён `block_bots`. Модерация Директа не могла открыть посадочную.

### Исправление на трекере
В `server/src/lib/tracking.js` + `track.js` добавлен allowlist рекламных роботов
(`YandexBot`, `YandexDirect`, Google AdsBot и т.п.): их пропускаем на оффер,
остальных ботов по-прежнему режем. Обычный curl/сканеры = 403.

Проверка:
```bash
curl -I -A 'Mozilla/5.0 (compatible; YandexBot/3.0)' https://trekerarbitrag.ru/click/0BL6esOO
# ожидается 302 → go.leadgid.ru
```

## Тексты объявлений
Убраны рисковые элементы:
- бренды: Booking, Apple Pay, Google Pay
- обещания обхода санкций / «в долларах» без контекста продукта

### Обязательно для PPM / зарубежной карты (ответ модерации Директа, 2026-07)
Без явного указания, что продвигается **выпуск зарубежной карты**, система
классифицирует оффер как банковские услуги и требует лицензию ЦБ.

В Title и/или Text должно быть: `зарубежная карта` или `выпуск зарубежной карты`.
Тогда документы не нужны. Пример:
- Title: `Зарубежная карта в поездки`
- Text: `Выпуск зарубежной карты онлайн. СБП. Промокод LG2026.`

## Что ещё проверить в кабинете Директа
1. После правки текстов — дождаться перемодерации (или отправить снова).
2. Баланс общего счёта > 0.
3. Лицензию грузить только если в тексте нет «зарубежной карты» и модерация снова просит.
