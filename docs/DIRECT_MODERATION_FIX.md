# Работа над ошибками: модерация РСЯ PPM

## Главная причина
Клик-ссылка `https://trekerarbitrag.ru/click/0BL6esOO` отдавала **403** для `YandexBot`,
потому что в кампании включён `block_bots`. Модерация Директа не могла открыть посадочную.

### Исправление на трекере
В `server/src/lib/tracking.js` + `track.js` добавлен allowlist рекламных роботов
(`YandexBot`, `YandexDirect`, Google AdsBot и т.п.): их пропускаем на оффер,
остальных ботов по-прежнему режем. Обычный curl/сканеры = 403.

Проверка:
```bash
curl -I -A 'Mozilla/5.0 (compatible; YandexBot/3.0)' https://trekerarbitrag.ru/click/0BL6esOO
# ожидается 302 → go.leadgid.ru
```

## Тексты объявлений
Убраны рисковые элементы для повторной/безопасной модерации:
- бренды: Booking, Apple Pay, Google Pay
- жёсткие формулировки «за границей / зарубежные / в долларах»
- заменены на нейтральные: «цифровая карта», «поездки», «подписки», «СБП», промокод LG2026

## Что ещё проверить в кабинете Директа
1. Для фин. услуг иногда нужны документы организации — если попросят, загрузить в Директе.
2. Баланс общего счёта > 0.
3. После правок объявления могут уйти на перемодерацию сами.
