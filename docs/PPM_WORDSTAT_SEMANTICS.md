Источник: Wordstat live + ручная чистка · дата: 2026-07-25  
Машиночитаемый файл: [`ppm-semantics.json`](./ppm-semantics.json)

## Что было не так в live

| Проблема | Итог |
|----------|------|
| Seed `Плати по миру - Выпуск карты` | `Invalid query` — бренд не использовать как seed |
| Seed `карта онлайн` | Залил мусор: осадки, СВО, натальная, Яндекс.Карты, бензин |
| Seed `оформление за минуты` | ТВ/тексты песен («пусть говорят…») |
| Seed `подписки` / hooks services | Почти всё упало в группу travel |
| Ассоциации «синяя карта», «сим карты» | Не платёжная карта — в минуса |

Автотаргетинг на старте: **выключен** (`suspended_on_start`).

## Отброшенный мусор (не лить)

Примеры из live, которые **не** должны попасть в группы:

- карты/осадки/погода/«в реальном времени»
- СВО / карта Украины
- натальная карта, матрица
- Яндекс.Карты, навигатор, маршрут, бензин
- займы на карту, скачать карту
- синяя карта / сим-карты для поездок
- платная дорога / межевание / «пусть говорят»

Фильтр для повторных прогонов: `scripts/filter-wordstat-ppm.mjs`.
