## 1. Ссылка для объявлений (обязательно)

Вставь **точно** эту ссылку в поле «Ссылка» объявления:

```
https://trekerarbitrag.ru/click/0BL6esOO?utm_campaign={campaign_id}&utm_content={ad_id}&utm_term={gbid}&source={source}
```

Пояснения:
- `{campaign_id}`, `{ad_id}`, `{gbid}`, `{source}` — макросы Директа (подставятся сами).
- `cost` в URL не передаём: в трекере уже стоит fallback **7 ₽** на клик (`cost_value`).
- Отображаемая ссылка (если просят): `trekerarbitrag.ru` или нейтральный бренд оффера — по модерации.

Проверка до запуска: открой ссылку **без макросов** в телефоне/браузере:

```
https://trekerarbitrag.ru/click/0BL6esOO
```

Должен открыться лендинг LeadGid / «Плати по миру».

1. [direct.yandex.ru](https://direct.yandex.ru) → логин `nitkinaleksandr`

4. Стратегия на старте: **Ручное управление ставками** (или «Максимум кликов» с ограничением CPC)
5. Дневной бюджет: **3000–5000 ₽**

7. Гео: **Россия** (старт: Москва, СПб, МО + города 500k+)
8. Расписание: круглосуточно или 09:00–23:00 МСК
9. Минус-фразы на уровне кампании (см. ниже)

```

```

## 3. Группы объявлений

### Группа A — Путешествия
- Тематика: travel / abroad / оплата за границей
- Креативы: из `ppm-rsya-travel-premium-v2.zip` + видео travel
- Заголовки (до 56 символов, варианты):
  - `Виртуальная карта для путешествий`
  - `Оплата за границей без проблем`
  - `Карта для поездок и Booking`
- Текст:
  - `Оформление онлайн. Apple Pay и Google Pay. Промокод LG2026 — скидка 500 ₽.`
  - `Пополнение рублями по СБП. Карта в валюте для поездок.`

### Группа B — Зарубежные сервисы
- Креативы: `ppm-rsya-services-premium-v3.zip` + видео subscriptions
- Заголовки:
  - `Оплата зарубежных сервисов`
  - `Карта для Spotify и сервисов`
  - `Пополнение в рублях — оплата в USD`
- Текст:
  - `Карта онлайн. Промокод LG2026 — 500 ₽ на открытие.`
  - `СБП, быстрый выпуск. Для подписок и онлайн-оплаты.`

### Группа C (опционально) — Премиум
- Видео premium + промокод `LGPREMIUM2026` (−1000 ₽)
- Заголовок: `Премиальная карта с выгодным курсом`
- Текст: `Выгодный курс для оплаты за границей. Промокод LGPREMIUM2026 — 1000 ₽.`

**Не писать в объявлениях:** обход санкций/ограничений, гарантии одобрения, P2P/вывод, крипта, gambling, adult, названия чужих брендов как «официально».

## 4. Таргетинг РСЯ

На старте:
- Площадки: **Рекламная сеть Яндекса**
- Автотаргетинг: можно включить **осторожно** или выключить и крутить по интересам
- Интересы / сегменты (ориентир): путешествия, финансы, банковские услуги, онлайн-шопинг, подписки
- Возраст: **25–45** (можно 18–55 на тесте)
- Устройства: все, смотри статистику через 2–3 дня

Минус-площадки — через 2–3 дня: вырежи мусор (игры, kids, random junk) по отчёту площадок.

Минус-слова кампании (пример):

```
бесплатно, халява, взлом, кряк, скачать, работа, вакансия, займ, кредит наличными, казино, ставки, 1xbet
```

## 6. Ставки и бюджет теста

| Параметр | Значение |
|----------|----------|
| Бюджет/день | 3–5 тыс. ₽ |
| CPC | 5–7 ₽ |
| Срок теста | 3–5 дней или ~15–25 тыс. ₽ расхода |
| Цель | клики → заявки/карты; смотреть EPC vs CPC |

Экономика оффера #7397:
- первая карта ~**896 ₽**
- премиум ~**2388 ₽**
- EPC сети ориентир ~**9–10 ₽** → при CPC 5–7 ₽ запас по ROI есть

Если CPC стабильно > EPC — режь ставки / площадки / слабые крео.
